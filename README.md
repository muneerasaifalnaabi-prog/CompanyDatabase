# Company Database System

## Sunday – ER Diagram Design

Designed the Entity-Relationship (ER) Diagram for the Company Database System including:
- Employees
- Departments
- Projects
- Dependents
- Managers and Supervisors

The ERD includes:
- Entities and Attributes
- Primary Keys
- Weak Entity (Dependent)
- One-to-Many and Many-to-Many Relationships
- Participation Constraints
- Recursive Relationships

---

## Monday – Relational Mapping

Converted the ER Diagram into Relational Database Mapping by:
- Creating relational tables
- Defining Primary Keys and Foreign Keys
- Mapping relationships
- Creating associative tables for many-to-many relationships
- Adding constraints and relationship attributes

---

## Tuesday – SQL Implementation
Implemented the database design using SQL (DDL) by:
- Creating all database tables
- Defining Primary Keys and Foreign Keys
- Implementing Employee–Project associative table
- Adding WorkingHours attribute
- Applying database constraints and relationships

The final result is a complete SQL schema for the Company Database System.
